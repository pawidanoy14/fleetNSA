# SMA Fleet Dashboard

เว็บแอปจริง (ไม่ใช่ mockup) สำหรับบริหารการใช้รถทีม SMA — ดึงข้อมูลสดจาก Google Sheets
2 ไฟล์ที่ทีม Operations ใช้งานอยู่แล้ว รวม 4 แหล่งข้อมูล (GPS, Kissflow, ทะเบียนคนขับ,
ใช้รถนอกเวลา) และแสดงผล 5 มุมมองตาม Design Brief เดิม

## สถาปัตยกรรม

- **Next.js (App Router)** — เพจฝั่ง client ดึงข้อมูลจาก `/api/data`
- **`/api/data`** (serverless function) — เรียก `lib/pipeline.mjs` ซึ่ง:
  1. ดึง CSV จาก Google Sheets 2 ไฟล์ผ่าน endpoint `gviz/tq` (เลือกแท็บด้วยชื่อ ไม่ใช่ gid
     จึงไม่พังเวลามีคนสลับ/เพิ่มแท็บ)
  2. Normalize เลขทะเบียนรถ (ตัดช่องว่าง/ขีด) แล้ว join ทั้ง 4 แหล่งด้วยทะเบียน/รหัสทีม
  3. อ่านค่าที่คำนวณไว้แล้วในแท็บ "กค.69" ฯลฯ (จำนวนวันกรอกขาด + ผลกระทบค่าใช้จ่าย)
     ตรงๆ แทนการเขียนสูตรซ้ำ — สูตรเดิมใน Google Sheet ผ่านการตรวจสอบแล้วว่าถูกต้อง
     (ดู "หมายเหตุด้านข้อมูล" ด้านล่าง)
  - ผลลัพธ์ cache ไว้ในหน่วยความจำ 5 นาที ต่อแท็บ กันการยิง Google Sheets ถี่เกินไป
- ไม่มีฐานข้อมูลแยกต่างหาก — Google Sheets **คือ** ฐานข้อมูล ทุกครั้งที่เปิดหน้าเว็บจะดึงข้อมูลสด

## Google Sheets ที่ต้องตั้งค่า

ทั้งสองไฟล์ต้องแชร์เป็น **"ทุกคนที่มีลิงก์ - ดูได้" (Anyone with the link — Viewer)**
ไม่ต้องเป็นสาธารณะทาง Google Search แค่ต้องไม่ต้อง login ก็เปิดได้

| ตัวแปร (env var) | ไฟล์ | แท็บที่ใช้ |
|---|---|---|
| `GPS_SHEET_ID` | การใช้รถทีมกิจ | การใช้รถทีมกิจกรรม, ใช้รถเกิน 22.00, รายชื่อคนขับ |
| `KISSFLOW_SHEET_ID` | รายงานการเดินรถใน kissflow | ข้อมูลจาก Kissflow (Data Dump), พค.69/มิย.69/กค.69 |

ค่า default ที่ตั้งไว้ใน `lib/config.mjs` คือ 2 ไฟล์ที่ให้มาตอนคุยงาน — เปลี่ยนได้ผ่าน
env var โดยไม่ต้องแก้โค้ด ถ้าย้ายไปสเปรดชีตใหม่

**สำคัญ:** ถ้ามีการเพิ่มแท็บเดือนใหม่ (เช่น "สค.69") ต้องเพิ่มเข้า
`MONTHLY_DASHBOARD_TABS` ใน `lib/config.mjs` ด้วย — โค้ดจะไม่เดาแท็บใหม่ให้เอง

## Deploy ขึ้น Vercel (ฟรี ไม่ต้องมีเซิร์ฟเวอร์เอง)

1. สร้างบัญชี [vercel.com](https://vercel.com) (ใช้ GitHub login ได้)
2. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo ใหม่ (private ก็ได้)
3. ใน Vercel: **Add New → Project** → เลือก repo นี้ → กด Deploy
   (ไม่ต้องตั้งค่าอะไรเพิ่ม Vercel จะรู้จัก Next.js เอง)
4. ถ้าจะใช้สเปรดชีตอื่นนอกจาก default: ไปที่ Project Settings → Environment Variables
   ใส่ `GPS_SHEET_ID` และ `KISSFLOW_SHEET_ID` แล้ว redeploy
5. เสร็จแล้วจะได้ลิงก์ `https://<ชื่อโปรเจกต์>.vercel.app` เปิดได้ทันทีทุกที่ ทุกอุปกรณ์
   (ต่อโดเมนของบริษัทเองภายหลังได้ผ่าน Vercel → Domains)

รันทดสอบในเครื่องตัวเอง (ต้องมี Node.js 18+):
```
npm install
npm run dev
# เปิด http://localhost:3000
```

## เชื่อมข้อมูลอัตโนมัติจาก Kissflow / GPS (ตามที่ตกลงกันไว้)

คุณระบุว่าจะตั้งให้ Kissflow และระบบ GPS (DTCUltimate) export/ส่งรายงานอัตโนมัติ
เข้า Google Sheet เดิมที่ใช้อยู่นี้ — เว็บแอปนี้ไม่ต้องแก้อะไรเพิ่ม เพราะดึงข้อมูลจาก
Sheet สดทุกครั้งอยู่แล้ว **ข้อควรระวังตอนตั้งค่าฝั่ง Kissflow/GPS:**

- ให้ export ไปยัง **แท็บเดิม** ที่ชื่อตรงกับใน `lib/config.mjs`
  (`ข้อมูลจาก Kissflow (Data Dump)`, `การใช้รถทีมกิจกรรม`, `ใช้รถเกิน 22.00`)
  หรือถ้าใช้แท็บใหม่ ต้องมาแก้ชื่อแท็บในไฟล์นี้ให้ตรง
- อย่าเปลี่ยนชื่อหัวคอลัมน์ (header) ของแท็บเหล่านี้ — โค้ดอ่านค่าด้วยชื่อคอลัมน์ ไม่ใช่ตำแหน่ง
- แท็บสรุปรายเดือน ("กค.69" ฯลฯ) ยังต้องอัปเดตด้วยสูตรเดิมของทีม Operations ตามปกติ —
  เว็บแอปแค่ "อ่าน" ค่าที่คำนวณไว้แล้ว ไม่ได้คำนวณเอง

## สิ่งที่พบระหว่างเชื่อมข้อมูลจริง (ควรรู้ไว้)

- **ทะเบียนคนขับ (SMA1-12) มีแค่ 12 คัน แต่แท็บติดตามการกรอก Kissflow มีถึง NSA1-16**
  แปลว่ามี 4 ทีม (NSA13-16) ที่ไม่มีรถ/ทะเบียนอยู่ในชีต "รายชื่อคนขับ" ตอนนี้ —
  แดชบอร์ดจะโชว์ทีมเหล่านี้เป็นตัวเลข NSA เฉยๆ (ไม่มีชื่อเล่น/คนขับ) จนกว่าจะเพิ่มข้อมูลในชีต
  ทะเบียนคนขับให้ครบ (มีเครื่องหมาย * กำกับในตาราง "รายคัน/ทีม")
- ช่วงเวลาข้อมูล GPS (มี.ค.-ก.ค.) และ Kissflow (พ.ค.-ก.ค.) ไม่เท่ากันตามที่ระบุใน brief —
  เดือนที่ไม่มีข้อมูล Kissflow จะโชว์ "-" แทนเปอร์เซ็นต์การกรอกแทนที่จะเดาเป็น 0%
- Kissflow มีทะเบียนรถ 6 คันที่ไม่อยู่ใน 12 คันหลัก (เช่น "2ขฉ7820") — เดาว่าเป็นรถทดแทน
  ที่ยืมข้ามทีม ระบบยังนับระยะทาง/ค่าใช้จ่ายของรายการเหล่านี้ในกลุ่ม "รหัสทีม (Region Code)"
  ได้ปกติ ถึงจะจับคู่ทะเบียนไม่เจอ

## ยังไม่ได้ทำ (แนะนำให้ทำต่อ)

- ระบบส่งรายงาน PDF อัตโนมัติทางอีเมล/LINE ทุกสิ้นเดือน (brief ข้อ 7)
- หน้า drill-down รายบุคคล (ประวัติการเดินทาง/วันที่กรอก-ไม่กรอก รายคน)
- สิทธิ์การเข้าถึงตามบทบาท (ผู้บริหาร/หัวหน้าทีม/พนักงาน) — ตอนนี้ใครมีลิงก์เปิดได้หมด
- ปุ่มดาวน์โหลด/พิมพ์ตารางเป็นรายงาน
